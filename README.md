Comparative Performance Evaluation of Machine Learning and Deep Learning Approaches for Pneumonia Detection Using Chest X-Ray Images

Project Overview

This project compares a traditional machine learning model (RBF-SVM) and a deep learning model (ResNet-18) for chest X-ray image classification.

Objectives

- Prepare a common dataset for both models.
- Train and evaluate RBF-SVM and ResNet-18 using MATLAB.
- Compare model performance using standard evaluation metrics.

Technologies

- MATLAB R2026a
- Histogram of Oriented Gradients (HOG)
- RBF-SVM
- ResNet-18
- Confusion matrices and performance metrics

Methodology

Dataset preparation → Image preprocessing → Model training → Model evaluation → Performance comparison

Evaluation Metrics

Accuracy, precision, recall, and F1-score.
